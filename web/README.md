# web

Next.js 16 (App Router) client for Tartib — one codebase for the desktop web app and the
installable mobile PWA. Plan: `docs/plans/07-web-foundation.md`; layout and stack:
`docs/plans/01-architecture.md`.

## Requirements

- **Node 26 LTS** (`nvm use` — pinned in `.nvmrc`) and **pnpm 12** (`corepack enable`).
- The API on `:8000` for anything that talks to `/api` (`make dev-api` from the repo root).

## Commands

| Command                     | Does                                                                     |
| --------------------------- | ------------------------------------------------------------------------ |
| `pnpm dev`                  | Next on `:3000`; `/api/*` is rewritten to `API_ORIGIN`                   |
| `pnpm build` / `pnpm start` | production build and server                                              |
| `pnpm test`                 | Vitest + Testing Library + MSW (jsdom)                                   |
| `pnpm typecheck`            | `tsc --noEmit` (strict, `noUncheckedIndexedAccess`)                      |
| `pnpm lint`                 | ESLint + Prettier check                                                  |
| `pnpm format`               | write Prettier formatting                                                |
| `pnpm gen:api`              | `openapi.json` → `src/api/schema.d.ts` (never hand-edit; `make gen-api`) |
| `pnpm e2e`                  | Playwright (`desktop` + `mobile` projects)                               |

## Configuration

| Var          | Default                 | Meaning                                                      |
| ------------ | ----------------------- | ------------------------------------------------------------ |
| `API_ORIGIN` | `http://localhost:8000` | target of the `/api` rewrite (set on Vercel to the API host) |

The app talks to its own origin only; everything under `/api` is proxied (D-02). Security headers
(CSP, HSTS, `nosniff`, `frame-ancestors 'none'`) are set in `next.config.ts` and asserted by
`src/next-config.test.ts`.

## Conventions

- Every `page.tsx` is a thin client component that renders `features/<name>`.
- Design tokens live in `src/design/` from WEB-01 on; `globals.css` holds only the neutral base.
- `AGENTS.md` in this directory is generated by Next itself — keep it, do not hand-write into it.
