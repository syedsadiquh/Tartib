The rules
·
One gesture for the top five. If it needs a modal, it's too slow.
·
Undo beats confirm. 10-second toast on everything reversible.
·
Show the consequence before you commit — "frees 18:30 → W2D2 starts earlier".
·
Tap = the obvious thing. Long-press = the other way. Skip is a pill; skip-until hides behind a hold.
·
Never ask what we can infer — est from the last similar task, priority from subject, deadline from "before Fri".
·
Only two hard confirms: writing the plan to Google Calendar, and disabling a habit.
Deliberately absent
·
Multi-step task wizard — capture is one line, fix fields later
·
"Which project?" prompts — subject is a chip, not a gate
·
Save buttons — every field writes on change
·
Onboarding tour — the first plan is the tour
